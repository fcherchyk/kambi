## Contexto

Usability must match mapa-mental so the same muscle memory works in both apps.

## Decisión

Every keyboard shortcut also has a visible button, and a "?" panel lists the shortcuts.

## Consecuencias

Actions are discoverable and accessible. Each new shortcut needs a button and an entry in the help panel.
